# 導入ガイド (Setup Guide)

SSPlayer for Ren'Py をご自身のゲームプロジェクトに導入する手順を解説します。

## 1. 必要環境
- **Ren'Py**: バージョン 8.x 系 (Python 3 ベース) が必要です。

## 2. ライブラリの配置
本リポジトリ内の **`game/spritestudio/`** フォルダを、ご自身のプロジェクトの `game/` ディレクトリ内にそのままコピーしてください。

> **内部構成**: このフォルダにはPythonスクリプト（`spritestudio.rpy` 等）と、各OS向けのネイティブライブラリ(Windows / macOS / Linux)がすべて含まれています。

## 3. 再生データ (`.ssab`) の配置
SpriteStudio で作成し、コンバータで変換された `.ssab`（および画像データ等）をゲームフォルダ内に配置します。
例えばプロジェクト内の `game/sprites/` フォルダを作成し、そこに配置します。

これで導入は完了です。実際の呼び出し方については [usage.md](usage.md) をご参照ください。
