# ⚠️ 仕様と制約事項 (Limitations & Scope)

現在の SpriteStudio Player for Ren'Py における制限事項・未実装の機能の一覧です。（サポートしている機能の一覧は利用ガイドを参照してください。）

このページは **この Player 固有** の内容を扱います。共通ランタイム由来で、すべての公式 Player に当てはまる制約 — `independent=true` パーツの逆再生・シーク、シーク時に通過フレームのイベントが発火しないこと、オーディオの逆再生非対応、ブレンドが同一 `.ssab` 内に限られること、`.ssab` の入力検証を行わないこと — は、ポータルの **[共通の制限事項](https://cri-middleware.github.io/SpriteStudio-Docs/ja/sdk/limitations/)** に集約されています。

## 未実装 (Not Yet Implemented)

> [!WARNING]
> - **Text / NineSlice パーツ** — 描画されません（空表示になります）。
> - **アニメーションのブレンド / ミキシング** — アニメーション間のクロスフェードや重み付き合成。
> - **Instance / Effect パーツ内の入れ子タイムラインイベント** — ルートアニメーションの UserData / Signal / Audio のみ対応。

## 部分的にサポート (Partially Supported)

> [!WARNING]
> - **ブレンドモード** — ブレンドは Ren'Py の `config.gl_blend_func` を経由するため、GL に相当がないモード（Division, Overlay）は Mix にフォールバックします。
> - **Mesh / Instance パーツのパーツ全体カラー** — `parts_color` は Normal / Shape パーツでは各頂点に適用されますが、Mesh パーツ全体への色味付けは現状アルファのみの近似です。
> - **Effect パーティクルへのマスク** — マスク / クリッピングが効くのは Normal・Mesh・Shape パーツです。Effect パーツが放出するパーティクルは、エディタ上でクリップされる場合でもクリップされずに描画されます。
> - **Instance パーツ内部へのパーツオーバーライド** — カラー / セル / 表示のオーバーライドが届くのは、呼び出したアニメーション自身のパーツまでです。Instance パーツの内部のパーツ（入れ子の子アニメーションは別プレイヤーとして動作します）には届きません。Instance パーツ自体を強制的に隠せば、その中身も描画されなくなります。
> - **パーツトラッキング（パーツへの追従）** — 追従させた子は常にスプライト**全体の手前**に描画され、パーツ間に差し込むことはできません。また反転（マイナススケール）したパーツでも子は反転しません（パーツの拡縮は絶対値として得られるためです）。位置と角度は正確ですが、左右反転しているだけのパーツは子には 180 度の回転として届きます（詳細は[使い方ガイド](usage.md)の「反転（鏡像）したパーツ」）。追従先に指定できるのは、そのプレイヤー自身が再生しているパックのパーツまでで、Instance パーツ内部のパーツは指定できません。

## オーディオ再生 (Audio Playback)

> [!NOTE]
> 通常の使い方（順再生で、スプライトを普通に表示 / 非表示する）ではそのまま鳴ります（`sfx` ミキサー上で再生されるため、プレイヤーの音量・ミュート設定も効きます）。注意が要るのは次のエッジケースだけです。
> - **逆再生の音は鳴らない** — アニメーションが逆方向（逆再生 / 負の速度）に進むとき、その音はスキップされます（音声は逆再生できないため）。
> - **シークで音はスクラブされない** — 音は再生中に再生ヘッドがそのフレームを通過した瞬間のみ発火します。フレームのジャンプ（`ss_set_frame`）ではスクラブも、飛ばした音の再発火もしません。
> - **手動管理のプレイヤーの停止** — `hide` / `scene` なら音は即座に止まります。`SSPlayer` を変数に保持して自分で差し替える場合は、`ss_stop_audio()`（または `ss_stop()`）を呼ぶと即停止します（呼ばなくても画面から外れて約 0.25 秒以内に自動停止）。
> - **サウンドファイルを `.ssab` と同梱** — テクスチャ同様、`.ssab` からの相対で解決します。存在しないファイルはスキップされます。

## パフォーマンス・プラットフォーム (Performance & Platform)

> [!NOTE]
> **パフォーマンスについて** — 描画は `ctypes` と Creator-Defined Displayable を介して行われるため、メッシュの頂点数が極端に多いアニメーションや、大量のパーティクルが多数重なるエフェクトでは、フレームレートに影響が出る可能性があります。

> [!WARNING]
> **プラットフォーム** — すべてのターゲットに対応しています: デスクトップ (Windows / macOS / Linux)、Android、iOS、Web。各プラットフォームへのエクスポート手順は[エクスポートガイド](export.md)を参照してください。プラットフォーム固有の注意点は以下です:
> - **Android** は Brain を APK の `lib/<abi>/` にネイティブライブラリとして同梱します。Android はそこからしかネイティブコードを読み込まず、パッケージ化されたゲームデータ内の `.so` はロードしないため、`.so` をアプリの jniLibs に配置する必要があります。SSPlayer の Android エクスポートフローはこれを自動で行いますが、素のランチャーでビルドする場合は一度だけ手動での配置が必要です。
> - **iOS** は macOS + Xcode が必要で、Brain ライブラリをアプリターゲットへ一度だけ手動で埋め込む必要があります（Ren'Py はサードパーティのネイティブコードを自動リンクできないため）。
> - **Web**（Pyodide/WASM）は Brain を `ctypes` で読み込めないため JS/WASM バインディングを使用しますが、これは Ren'Py のエクスポータが自動では同梱しません — Web エクスポートのたびに、ゲーム開始前に WASM モジュールを読み込む手動ステップが必要です。
